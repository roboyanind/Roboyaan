ROBOYAAN WEBSITE
================
To view: open index.html in your browser (double-click).
Keep all files and the "assets" folder together. Do not move index.html out of this folder.

Files
  index.html      the page content
  style.css       design
  script.js       menu, tabs, workshop planner, contact form
  assets/         photos and logo
  favicon files   browser tab icon

To put it online for free: Cloudflare Pages -> upload this whole folder.
